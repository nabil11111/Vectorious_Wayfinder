# Map data

The sign-in artwork and the dispatcher dashboard's fleet map draw Sri Lanka's 25 districts. The shapes are derived
district shapes: schematic, not GPS. Nothing in the app places a shop, a depot or a truck by real coordinates.

| Module | What it holds |
| --- | --- |
| `apps/web/src/lib/map/login-artwork-shapes.ts` | The sign-in artwork: every district in one 600 x 660 frame, marked served where either depot has shops. |
| `apps/web/src/lib/map/fleet-map-shapes.ts` | The fleet map's three views (Peliyagoda, Kandy, Both), each a 340 x 280 frame: the districts, the depot anchors and one connection from each depot to each district it serves. |
| `apps/web/src/lib/map/geometry.ts` | `pointAt` and `angleAt`, for placing a vehicle pointer along a connection. |

Both shape modules are generated by `scripts/map-shapes.mjs` and committed. They are not built at build time.

## Where the shapes come from

- **District boundaries:** geoBoundaries gbOpen, Sri Lanka ADM2, boundary year 2017, sourced upstream from
  OpenStreetMap. Pinned download:
  <https://media.githubusercontent.com/media/wmgeolab/geoBoundaries/9469f09/releaseData/gbOpen/LKA/ADM2/geoBoundaries-LKA-ADM2.geojson>
  (SHA-256 `47b5ae26225e62052686b6a7ab1dadcaab96d7b968f618b752151f4dc8943a4d`).
- **Depot anchors:** the town centres of Peliyagoda and Kandy from OpenStreetMap Nominatim, not surveyed depot
  premises. They are constants in the script.
- **Served districts:** the districts where a depot has shops in `data/shared/outlets.csv`.

(c) OpenStreetMap contributors. The data is under the Open Database License (ODbL) 1.0:
<https://www.openstreetmap.org/copyright>. The shapes in this repo are derived from it and stay under the ODbL.
The GeoJSON itself is not kept in the repo.

## How they are made

The script repeats the maths of the design's own map scripts, so the screens match the Figma frames:

- One north-up Mercator projection per frame. The artwork fits every district with 12 px of padding. Each fleet
  map view fits its own box, and district outlines are clipped to the frame.
- A district's centre is the centroid of its largest ring.
- A connection is a quadratic curve from the depot anchor to the district centre, with the design's inland bends
  for Colombo, Gampaha, Kandy and Puttalam. It must stay on land at 241 points along the curve, or the script
  fails. It is stored as 41 evenly spaced points.
- Outlines are simplified (Douglas-Peucker) and rounded to 0.1 px so each module stays under 60 KB: the artwork
  at 0.25 px, and the fleet map at 0.6 px, because its three views and 24 connections come to 84 KB at 0.25 px.
  Every island is kept. Depot anchors, centres and connection points keep 0.01 px, which pointer angles need.

## Rebuilding

```sh
curl -L -o /tmp/districts.geojson \
  https://media.githubusercontent.com/media/wmgeolab/geoBoundaries/9469f09/releaseData/gbOpen/LKA/ADM2/geoBoundaries-LKA-ADM2.geojson
node scripts/map-shapes.mjs /tmp/districts.geojson
npm test -w apps/web
```

The script prints each module's size. It writes nothing and exits with an error if a connection leaves land or a
module is over 60 KB. Commit both modules after a rebuild.
